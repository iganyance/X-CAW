# CAW X – illustration bank

Illustrations for the image cards of [@centralasiawire](https://x.com/centralasiawire), the X account of Central Asia Wire (centralasiawire.com).

- One folder per country (`KZ/` – Kazakhstan, `UZ/` – Uzbekistan). Files are named `<COUNTRY>_<class>_<NN>.png`, 1536×1024.
- `bank.json` lists every image with its news class, season, alt text, raw link and sha256.
- Each picture is a generic scene of the country for a class of news (power, money, oil and gas, mining, transport, diplomacy, society, agriculture and water, industry and power). It does not depict any specific event.
- Style: flat risograph-like editorial illustration, CAW palette (navy #132345, amber #E4AB51) plus one country ink (Kazakhstan – turquoise, Uzbekistan – lavender), listed as `accent` in `bank.json`.
